Consulte o [README principal](../README.md) e a [licença da raiz](../LICENSE.md). Créditos e licenças específicos deste módulo permanecem nos documentos abaixo.

As cópias marcadas com `SUBSTITUIDO` foram movidas para `substituidos/`.
A estrutura interna conserva a pasta de origem de cada arquivo.
Nenhuma cópia histórica foi descartada ou teve seu conteúdo alterado.

Esses arquivos registram versões anteriores. Não são entradas atuais dos jogos;
seus caminhos relativos refletem a estrutura antiga e não são corrigidos para execução.

O [mapa de movimentos](mapa-de-movimentos.json) registra os caminhos anteriores
e atuais dos documentos, materiais de desenvolvimento e cópias substituídas.
Para jogar, use o [portal](../index.html). Para localizar os jogos, consulte
o [mapa por história](../historias/README.md).
